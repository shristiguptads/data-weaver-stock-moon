# 🌙 Data Weaver: Stock Prices vs Moon Phases

This project explores whether stock market behavior shows any noticeable variation across lunar moon phases by mashing **financial market data** with **astronomical data**.

⚠️ This is exploratory analysis only and does NOT claim predictive or trading value.

---

## 🚀 Features
- Interactive Streamlit dashboard
- Historical stock data via Yahoo Finance
- Lunar phase computation for each trading day
- Price visualization with moon phase markers
- Aggregated return analysis by moon phase
- Kiro-assisted development artifacts included

---

## 🧠 Tech Stack
- Python
- Streamlit
- yfinance
- pandas, numpy
- plotly
- Kiro
